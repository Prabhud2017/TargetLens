TARGET LENS AI

Privacy Policy for Target Lens AI

1. Summary

Target Lens AI is a debugging and productivity extension for Adobe Target and related Adobe Experience Platform Web SDK workflows. To provide that functionality, the extension may access information from the webpages you visit, selected network requests made by those pages, and credentials or settings that you enter into the extension.

The extension does not sell your personal information, does not use your data for advertising, and does not run a separate behavioral analytics or telemetry backend of its own. However, if you choose to use optional AI or Adobe API features, the extension will send the information required for those requested features directly to the relevant third-party or Adobe service.

Because the extension runs on webpages you open, any personal or sensitive information present on those webpages may be processed by the extension locally in your browser and may be included in requests you intentionally send through optional AI or API features. Do not use the extension on pages or with data you are not authorized to inspect.

2. Information the extension may process

A. Website and browsing data

The extension may access and process information from webpages you visit, including:

  • Page URL, page title, viewport size, and page structure.
  • HTML or a structured outline of the current page or selected page sections.
  • Visible text such as headings, buttons, calls to action, labels, and form-related content.
  • Element selectors, DOM structure, and layout information used for debugging or code generation.
  • Adobe Target / Web SDK / at.js related network request and response details visible in the browser.
  • Visitor identifiers or diagnostic values exposed on the page, such as ECID, Target IDs, activity metadata, or related response tokens.

B. User-provided data

If you enter information into the extension, it may process and store:

  • API keys for AI providers such as OpenAI, Anthropic, or Google Gemini.
  • Adobe Target-related configuration values such as client code, IMS organization ID, client ID, bearer/access tokens, and profile API tokens.
  • Prompts, offer names, debugging settings, saved preferences, and generated code.
  • Optional images or attachments that you choose to provide to AI-assisted features.

C. Sensitive categories

Depending on the webpage you use it on, the extension may process categories that Chrome Web Store treats as sensitive, including authentication information (for example API keys, bearer tokens, and credentials you enter) and web browsing activity (for example pages visited, page content, and related network activity needed for the extension’s core functionality).

3. How the extension uses information

  • To detect Adobe Target, at.js, and Adobe Experience Platform Web SDK implementations on the page.
  • To display Target activities, offers, selectors, profile information, IDs, and relevant network calls.
  • To help you inspect, validate, copy, export, or generate Adobe Target-related code or offer content.
  • To save extension settings and keep your configured preferences available in your browser.
  • To connect to Adobe APIs you explicitly configure, such as Adobe Target Admin API or Adobe Target Profile API.
  • To send prompts and selected page context to the AI provider you choose, when you intentionally invoke AI-assisted features.

4. When information is shared outside your browser

The extension shares information only when needed to perform a feature you choose to use. Depending on your configuration, information may be sent directly from your browser to the following service providers:

  • Adobe services, such as Adobe Target API endpoints and related Adobe MCP endpoints, when you configure and use Adobe integration features.
  • OpenAI, if you configure an OpenAI API key and use OpenAI-powered features.
  • Anthropic, if you configure an Anthropic API key and use Anthropic-powered features.
  • Google Gemini, if you configure a Gemini API key and use Gemini-powered features.

The specific information sent depends on the feature you run, but may include prompts, page metadata, page structure, selected page content, generated code requests, images you attach, and credentials required to authenticate the request.

The extension does not sell personal information, does not share data with data brokers, and does not use accessed data for unrelated advertising or marketing.

5. Local storage and retention

Target Lens AI stores settings and working data locally in your browser using Chrome extension storage (for example chrome.storage.local) so the extension can function across browser sessions.

  • Saved settings may include API keys, tokens, client identifiers, preferences, and certain generated outputs.
  • Debugging data and cached records may be stored locally to support the current page, current tab, or recent extension actions.
  • Locally stored data remains until you change it, clear extension storage, or uninstall the extension, unless the extension overwrites or removes it earlier.

If you uninstall the extension, Chrome typically removes the extension’s local storage. You can also clear or replace saved values in the extension settings.

6. Your choices

  • You can choose whether to enter API keys, tokens, or other credentials into the extension.
  • You can choose whether to use optional AI-powered features.
  • You can choose whether to use Adobe API integrations such as profile or admin API calls.
  • You can remove saved values by updating settings, clearing extension storage, or uninstalling the extension.
  • You can restrict or disable extension access through your browser’s extension permission controls.

7. Data security

The extension is designed to keep most processing in your browser and to send data externally only when a requested feature requires it. Still, no method of electronic storage or transmission is completely secure. You are responsible for protecting any credentials you enter and for using the extension only in environments where you are authorized to inspect page content and network traffic.

8. Children’s privacy

This extension is not directed to children and is intended for users who are old enough to use browser extensions and related developer tools in their jurisdiction.

9. Changes to this Privacy Policy

This Privacy Policy may be updated from time to time to reflect changes to the extension or to legal, operational, or Chrome Web Store requirements. When this page is updated, the effective date at the top of this page will be revised.

10. Contact

For support or privacy questions, please use the support contact or support URL provided in the Chrome Web Store listing for Target Lens AI, or the contact method published by the developer on the extension’s website or repository.
